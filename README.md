# littlerip

A tiny open-source command that turns the terminal into one word:

```text
littlerip
```

## Install

Install LittleRip globally with npm:

```sh
npm install --global littlerip
```

Then run it from any directory:

```sh
littlerip
```

Press **Ctrl+C** to leave LittleRip and return to the original terminal screen.

## Options

```text
littlerip --help
littlerip --version
```

## Requirements

- Node.js 18 or newer
- macOS, Linux, or Windows

## Uninstall

```sh
npm uninstall --global littlerip
```
